## 💗 Sobre o Projeto

A **Calculadora Simples** é uma aplicação web desenvolvida com **React JS** como atividade prática em sala de aula.

O projeto tem como objetivo desenvolver uma calculadora capaz de realizar operações matemáticas básicas utilizando dois números informados pelo usuário.

A aplicação permite escolher entre:

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão

Após escolher a operação, o usuário pode clicar em **Calcular** para visualizar o resultado ou em **Limpar** para apagar os dados preenchidos.

## 🎯 Objetivo

O objetivo deste projeto é colocar em prática conhecimentos fundamentais do **React JS**, principalmente a criação de componentes e a interação com o usuário.

Durante o desenvolvimento foram trabalhados:

- ⚛️ Componentes React

- 🔢 Operações matemáticas
- 🎨 CSS Modules
